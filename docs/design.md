# agent-toolkit 설계와 검증 기준

승인된 범위: 로컬 agent-skills와 agent-harnesses의 개인 도구 라이브러리. React + TypeScript + Vite, 별도 private Git 저장소, Vercel 배포.

기본 화면은 왼쪽 분류와 중앙 카탈로그로 구성한다. 은은한 회색(#f7f8fa), 흰색 패널(#fff), 어두운 본문(#242938), 보조 글자(#737b8e), 경계(#e7eaf0), 파란 강조(#315be8)를 사용한다. 자체 호스팅 Noto Sans KR을 사용하며 왼쪽 정렬, 짧은 소개와 명확한 복사 버튼을 우선한다. 과한 애니메이션과 외부 미디어는 사용하지 않는다.

데이터는 원본을 읽는 로컬 동기화와 온라인 업데이트 확인을 분리한다. 한국어 설명은 자동 추출로 덮어쓰지 않는다. 하네스 호출 스킬은 중복 집계하지 않는다. 외부 원문과 실행 결과를 저장하지 않는다.

완료 검증:
- 44개 항목(2/11/31), 중복 ID 없음, 두 humanizer 별칭 구분
- 검색, 분야와 유형 필터, 상세 URL 새로고침, 복사와 맥락 입력
- 즐겨찾기 저장/복원, 빈 결과, 잘못된 상세 ID, 어두운 테마
- 모바일 화면에서 가로 넘침 없음과 메뉴 작동
- 원본 폴더의 변경·삭제·추가, 다른 스킬 변경 제외, 원본 미확정과 조회 실패
- 테스트와 TypeScript 빌드, 원격 커밋 및 Vercel 배포, 비인증 보호 확인

후속 범위: 로컬 자동 설치/실행, 기기 간 즐겨찾기 동기화, 브라우저 직접 편집은 포함하지 않는다.
